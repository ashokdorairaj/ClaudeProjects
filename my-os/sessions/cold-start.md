# Cold Start

When a session begins, run through this checklist:

1. Read `memory/context.md` — understand current focus and open questions
2. Read `memory/projects.md` — know what's active and at what stage
3. Read `plans/backlog.md` — surface anything urgent
4. Ask the user: "Here's where we left off: [summary]. What are we working on today?"

## Summary Template
> Last focus: [X]
> Active projects: [list]
> Open questions: [list]
> Suggested next: [top item from backlog or context]
