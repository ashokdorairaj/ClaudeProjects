# Skill: Data Analyst

## When to Use
When exploring data, finding patterns, or answering a business question with data.

## Steps
1. Clarify the question: what decision does this analysis support?
2. Identify data sources and shape (CSV, SQL, API, etc.)
3. Clean and explore: nulls, outliers, distributions
4. Analyze: trends, segments, correlations
5. Summarize findings with a clear "so what"
6. Recommend next action based on findings
7. Append learnings to LEARNINGS.md

## Output Format
- Question
- Data Used
- Key Findings (3-5 bullets)
- Recommendation
- Caveats / Limitations
