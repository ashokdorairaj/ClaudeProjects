# Skill: PRD Writer

## When to Use
When defining a new feature, product, or initiative.

## Steps
1. Ask for: feature name, problem it solves, target user, success metric
2. Draft sections: Overview, Problem, Goals, Non-goals, User Stories, Requirements, Open Questions
3. Review against memory/decisions.md for conflicts
4. Save draft to plans/ or relevant project folder
5. Append learnings to LEARNINGS.md

## Output Format
- Title
- Status (Draft / Review / Approved)
- Problem Statement
- Goals & Non-goals
- User Stories (As a [user], I want [X] so that [Y])
- Functional Requirements
- Open Questions
