# Skill: Prioritize

## When to Use
When the backlog is overwhelming or you need to decide what to work on next.

## Steps
1. Pull items from plans/backlog.md
2. Ask for any constraints (deadline, dependencies, effort)
3. Score each item: Impact (1-3) × Confidence (1-3) / Effort (1-3)
4. Rank by score, flag any must-dos regardless of score
5. Produce a recommended order with reasoning
6. Optionally update plans/roadmap.md
7. Append learnings to LEARNINGS.md

## Output Format
| Rank | Item | Impact | Confidence | Effort | Score | Reasoning |
